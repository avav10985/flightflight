# 四軸 PID 調校步驟（拘束測試）

> 對象：`Drone_FC_Full` + `Ground_TX_OOP`（或 `Ground_TX_ESP32`）
> 建立：2026-09-07

## 這份怎麼來的

方法論改編自 Joop Brokking 的 YMFC-AL（brokking.net）。
**但增益數字全部重算，不可互抄** —— 他是 rate PID（誤差＝角速度 deg/s、輸出 µs），
我們是單層角度 PID（誤差＝角度 deg）。他的 `P 1.3 / I 0.04 / D 18.0`
乘的是完全不同的物理量，照抄會炸機。**方法可用，數字不可用。**

---

## 0. 開始前

**安全**
- 拘束架必須真的牢固，飛機掙脫 = 裝了槳的絞肉機
- **要裝槳**（調 PID 沒有氣動力回饋就沒意義；拔槳是 ESC 校準時的事，不是這裡）
- 人站在旋轉面之外，不要在正上方／正前方
- 手把隨時能撥回 **mode 00** 斷動力

**前置條件（缺一不可）**
- [ ] ESC 油門行程校準已做完（`esccal` → `esccalmin`）
- [ ] IMU 完整校準已做（`calfull`），飛機水平靜置時 Serial 顯示 R/P 接近 0
- [ ] FC 與手把**成對燒**過 PID 回傳版韌體（否則選單顯示的不是飛機實際值）

## 1. 兩條調參路徑

| | 手把選單（推薦） | FC Serial（USB，只能地面） |
|---|---|---|
| Kp | ＋/－ 步進 **0.1** | `kp 1.2` |
| Ki | 步進 **0.005** | `ki 0.02` |
| Kd | 步進 **0.05** | `kd 0.4` |
| KpY | 步進 **0.1** | `ypp 0.9` |
| KiY | 步進 **0.005** | `yi 0.02` |
| 看目前值 | 選單直接顯示 | `p` |
| **存進 NVS** | 「保存PID」按 OK | ❌ **沒有這個指令** |

> ⚠️ **Serial 調的值不會存進 NVS。** `savePIDToNVS()` 只有 paramID 102
> （手把選單「保存PID」）會呼叫。用 Serial 調完重開機就全沒了 ——
> **最後一定要用手把按一次「保存PID」**。

## 2. 我們的 PID 結構（調之前必須知道）

- **Roll 和 Pitch 共用同一組 `Kp_rp/Ki_rp/Kd_rp`**，不能分開調。
  調好 roll 等於 pitch 也定了（和 Brokking 同樣的簡化）。
- 誤差是**角度**（deg），不是角速度。
- D 項對**量測**微分（`−Kd × gyroRate`），不是對誤差 →
  推搖桿不會產生 derivative kick（這點比 Brokking 的寫法好）。
- 搖桿滿舵＝ **±20°**（`MAX_ANGLE`）；yaw 滿舵＝ **±45°/s**（`MAX_YAWRATE`）。
- I 積分限幅 **±100**（`I_LIMIT`）。
- 未武裝或油門 < 20 時 I 項自動歸零（anti-windup）。
- **Yaw 沒有 D 項**（程式裡就沒有），不用找。

---

## 3. 調校順序

**起始值：`Kp=1.0  Ki=0  Kd=0`**（先把 Ki、Kd 歸零，一次只動一個）

### Step 1 — Kp（roll／pitch）
- 從 **1.0** 開始，每次 **+0.1**
- 手推機身一個小角度後放手，看它回正
- 🎯 目標：**回正快、只過衝一兩下**
- ⛔ 出現持續震盪（等幅或發散）→ **退回 30%**
- 記下這個值再往下走

### Step 2 — Kd
- Kp 固定，Kd 從 **0** 開始 **+0.05**
- 🎯 目標：把 Step 1 的過衝壓掉，回正變乾脆
- ⛔ 過頭徵兆：**馬達高頻抖動／嗡嗡聲**、對輕微震動過度敏感 → 退一格
- 我們的 D 吃 MPU6050 原始角速度，雜訊會被放大，**Kd 不要貪**

### Step 3 — Ki
- 最後才加，從 **0.005** 開始
- 🎯 目標：消除「穩住了但固定偏一個角度回不去」的殘留誤差
- ⛔ 過頭徵兆：慢速搖擺（週期 1 秒以上）、鬆手後緩緩盪過頭
- 多數情況 **0.01～0.03** 就夠

### Step 4 — Yaw（KpY／KiY）
- 拘束架改成**只放開 yaw 軸**
- KpY 從 **0.8** 開始 +0.1 → 🎯 轉頭停得住、不彈回
- KiY 保持很小（**0.01～0.02**），消除慢慢自轉的漂移

### Step 5 — 保存
1. 手把選單 → **「保存PID」** → 按 OK
2. 螢幕跳「PID 已存飛機」確認屏 ——
   上面顯示的是**飛機回傳的實際值**，不是手把本地值，**這就是存成功的證明**
3. FC Serial 送 `p` 再核對一次

## 4. 症狀對照表

| 症狀 | 原因 | 動作 |
|---|---|---|
| 快速震盪、馬達尖銳嗡嗡 | Kp 或 Kd 太大 | **先降 Kd**，再降 Kp |
| 慢速大幅搖擺（>1 秒週期） | Ki 太大 | 降 Ki |
| 反應遲鈍、推了才慢慢動 | Kp 太小 | 加 Kp |
| 停得住但固定偏一角 | Ki 太小 | 加 Ki |
| 過衝好幾下才穩 | Kd 太小 | 加 Kd |
| **一武裝就往固定一邊翻** | **不是 PID 問題** — 馬達序號／旋向或混控符號錯 | **停**，查接線 |
| 調了值飛機沒反應 | 封包丟失 or 沒成對燒 | 看 FC Serial 有沒有印「收到 Kp=」 |

## 6. 兩個 Brokking 踩過、我們不用踩的坑

1. **NaN 卡死**：他用 `asin(acc/total)`，輸入 >1 時回傳 NaN，而互補濾波會讓 NaN
   **永久卡住**、飛機失控（他 v1.1／v1.2 連修兩版）。
   我們用 `atan2f`，對所有輸入都有定義 → **天生免疫，不用改**。
2. **增益不可抄**：見本文開頭。
